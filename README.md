# CommandCentreCore

> The next generation of CommandCentre infrastructure

## Overview
This is a fork of the upstream Marketing Command Centre backend. This fork will eventually be merged with upstream, once it is fully refactored and supports all the features I want it to. I am keeping this seperate from upstream to prevent half-baked features from getting pushed too early.

The ultimate goal of this refactor is to consolidate all tenancy-related configuration data within the backend, and make the backend a truly extensible core from which other developers can add/remove/modify/create functionality.
